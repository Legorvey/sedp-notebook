## 2. Disagreements & Cross-Team Reconciliations

1. **Route Language Convention (`UX` `/kurikulum` vs `Full-Stack` `/belajar` vs `QA` `/learn`):**
   - _Resolution:_ Standardized all 9 planning artifacts on **Indonesian canonical routes** (`/kurikulum`, `/lab`, `/latihan`, `/referensi`, `/tentang`) matching the Indonesian UI prose requirement in `PROJECT_BRIEF_SEDP_Learning_Hub.md` §3, with clean URL slugs and zero English duplicates.
2. **`@xyflow/react` vs Custom Accessible SVG for End-to-End Explorer (`01_MULTI_AGENT` prompt option vs `Full-Stack` / `QA` / `UX`):**
   - _Resolution:_ Use **custom React `<svg>` + native HTML controls** for Vertical Slice `1.3-01` and V1 Lab `(c)` (better WCAG 2.5.7 compliance, zero drag-only barriers, crisp mobile node-stepper fallback, smaller JS footprint), reserving `@xyflow/react@13.0.2` only if a future multi-BU graph genuinely requires dynamic pan/zoom.
3. **MDX Pipeline (`@next/mdx` vs `next-mdx-remote` vs `@mdx-js/mdx`):**
   - _Resolution:_ Standardized on build-time `@mdx-js/mdx@3` (`compile`/`evaluate` in async RSC) + `gray-matter@4` + `zod@4` reading `content/lessons/*.mdx` so dual-ordering indexes, provenance gates, and routes stay unified without `@mdx-js/loader` webpack assumptions.
4. **`SEDP Learning Hub` Brand Name vs Trademark Risk (`Product` vs `Legal`):**
   - _Resolution:_ Retain `"SEDP Learning Hub"` as working title during planning while **requiring immediate `"Catatan Belajar Independen Sistem Kabel Laut"` subtitle + non-affiliation meta/footer/about disclosures**, and surfacing final brand confirmation (`SEDP Learning Hub` vs neutral Indonesian brand) for explicit owner approval before public deployment.
5. **Simulator `(j)` Marine Survey Scope (`Subsea Eng` Tier 1 vs `Curriculum` Strict Gating):**
   - _Resolution:_ Keep Lab `(j)` in V1.1 and **blocked pending owner supply of `Catatan SEDP-1.pdf` / M1.5** (do not expose dead nav links per `R-24`; Tier 1 public-standards preview only built if owner explicitly opts in during Phase 1/M5).
6. **Phase 0A `button.tsx` & `globals.css` Baseline Debt (`QA` + `UX` + `Full-Stack`):**
   - _Resolution:_ Scheduled immediate remediation of `button.tsx`, `globals.css` `@custom-variant dark`, `ThemeToggle` persistence, and `next.config.ts` security headers as **Milestone M0** (prerequisite before Vertical Slice `1.3-01`).
