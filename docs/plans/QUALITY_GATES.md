### 1B. Mandatory Manual Accessibility Acceptance Matrix `[PROPOSED Release Blocker]`

Automated `@axe-core/playwright` scans catch DOM/contrast regressions only; **zero axe violations does NOT prove full WCAG 2.2 AA compliance**. Every M1+ milestone requires manual tester sign-off covering:

1. **Screen Reader Pass (NVDA / Narrator / VoiceOver):** Verify `aria-live="polite"` announcements on Lab `(c)` node selection and discrete simulation triggers (`"Simulasikan Sinyal"`), `role="alert"` error messaging, `role="status"` loading copy, and `<th scope>` / `<caption>` table reading on simulator fallbacks, `/tentang/sumber`, and `/tentang/verifikasi-fakta`.
2. **Exploratory Keyboard Navigation:** Complete every primary task with keyboard only (`Tab`, `Shift+Tab`, `Enter`, `Space`, `Escape` focus return to opener, `WCAG 2.4.3` logical tab order, `2.1.2` zero traps, `tabIndex={0}` scrolling on `overflow-x-auto` KaTeX/tables, and `2.4.11` sticky-header clearance via `scroll-padding-top`).
3. **`200%` Text-Only Zoom & Text Spacing (`WCAG 1.4.4`, `1.4.12`):** Verify browser text-only zoom (`200%`) on narrow viewports and WCAG 1.4.12 spacing overrides without text clipping or control overlap.
4. **Diagram-to-Table Parity:** Visually and structurally cross-check interactive `.abyss-bay` SVGs / Recharts outputs against synchronized HTML `<table>` rows after parameter edits, mode toggles, and `"Atur Ulang Parameter"`.
5. **Mobile Touch & Soft-Keyboard Check:** Inspect touch usability (`>= 44x44px` boxes, `>= 8px` inter-target spacing, continuous sweep across `<600px`, `600px-1024px`, `>1024px`) and real/emulated soft-keyboard input clearance across simulators, quizzes, and glossary search.
6. **Error, Empty, Loading & Recovery Walkthrough:** Trigger invalid ranges, zero filter matches, `1.4`/`1.5`/404 unavailable views, quiz validation focus jump, and `sedp.progress.v1` reset, confirming clear cause + working recovery action (`R-27`).

## 2. Mandatory CI Release Blockers (`.github/workflows/ci.yml`) `[PROPOSED M0+ Updates Beyond Phase 0A Baseline]`

Phase 0A CI currently executes steps `1-3`, `7-8` (`lint`, `format:check`, `typecheck`, `test`, `build`, baseline `test:e2e`); Milestone **M0** extends CI with the content, asset, security, contrast, and axe blockers below so no PR merges unless every automated check exits `0`:

1. **`pnpm lint` (`eslint .`):** 0 errors, 0 warnings; block un-audited `dangerouslySetInnerHTML`.
2. **`pnpm format:check` (`prettier --check .`):** Clean formatting parity across repo code, configs, `content/`, and `docs/plans/` (keeping owner-authored root briefs untouched if `.prettierignore`d or scoped explicitly).
3. **`pnpm typecheck` (`next typegen && tsc --noEmit`):** Strict TypeScript 5 passes on fresh checkout.
4. **`pnpm verify:content` (Added in M0: Custom Build/CI Gate Script):**
   - Validates all MDX frontmatter, `sources.json`, `assets-manifest.json`, `fact-checks.json`, `glossary.json`, and `quizzes/*.json` via **Zod `.strict()`** schemas forbidding private audit keys (`filename`, `private_storage_ref`, `internal_deck_trigger`, `file_on_disk`, `audit_policy`).
   - Fails if any publicly rendered item or `content/sources.json` entry has `rights_status !== "CLEARED"` or `public_reuse_allowed !== true`, lacks non-empty `ownership`/`license`/`attribution`, omits a valid `YYYY-MM-DD` `checked_at` date, or contains `/\b(TBD|TODO|FIXME|placeholder)\b|<verify|UNINSPECTED/i`.
   - Enforces conditional `related_labs` linking (`isLabShipped()`) so unbuilt `/lab/*` slugs never render (`R-24`), and fails if Module `1.4` or unsourced `1.5` exposes fabricated lessons.
   - Scans **both `src/` and `content/`** case-insensitively for em dashes (`U+2014`), restricted strings (`"Internal Use Only"`, `"Slides marked confidential"`, `"[Restricted]"`, `"SubOptic 2022"`, `"OSM BDO"`, `"Rumpon"`), internal deck/file markers (`"Modul_1.1"`, `"Modul 1.2"`, `"Module 1.3"`, `"NEC Advances"`, `"Catatan SEDP-1"`, `"PROJECT_BRIEF"`, `"src-sedp-"`, `"src-nec-"`, `"src-owner-"`, trainer PII), and runtime Next.js `/api/v1/**` handlers or fetch calls.
5. **`pnpm verify:assets` (Added in M0):** Fails if any `.pdf`, `.pptx`, `.ppt`, `.docx`, `.xlsx`, `.env` (other than `.env.example`), or `sources-private/` files appear in `public/` or Git index (`git ls-files`), if `*NEC*Internal*.pdf` / `NEC Advances*.pdf` still sits inside the workspace or `sources-private/`, or if any non-allowlisted file under `public/` (outside `favicon.ico` / `robots.txt` / `sitemap.xml`) lacks a `content/assets-manifest.json` + `content/sources.json` match with **both** `rights_status === "CLEARED"` and **`media_redistribution_allowed === true`** (`reuse_scope !== "CITATION_AND_FACT_SYNTHESIS_ONLY"`).
6. **`pnpm audit --audit-level=high` (Added in M0):** Fails on unresolved high/critical runtime dependency advisories.
7. **`pnpm test`:** 100% pass across all unit math vectors, Zod `.strict()` provenance/content validators, repo-native WCAG contrast tests, and sync client component tests.
8. **`pnpm build` + `pnpm test:e2e`:** Clean production build + full Playwright Desktop, Mobile `hasTouch`, `@axe-core/playwright` (`Light`, `Dark`, `.abyss-bay`), `200%` text scaling, and HTTP CSP header parity verification (paired with Section 1B Manual Accessibility sign-off).
